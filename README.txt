HOW TO RUN (LOCAL)
------------------
1) Install:
   pip install -U pandas numpy scikit-learn joblib matplotlib

2) Open notebook:
   jupyter notebook Student_Behaviour_And_Performance.ipynb

3) Run all cells.
   The trained models will be saved to a folder named: models/
